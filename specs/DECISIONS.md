# 设计决策

## AD-001: 单体 Web 应用

**决策**: MVP 只开发 apps/web，不使用 apps/native

**理由**: 需求未提及移动端，Web 端可快速验证

---

## AD-002: 数据库选型

**决策**: PostgreSQL + Prisma

**理由**: 项目已配置，时序数据量不大

---

## AD-003: API 设计

**决策**: tRPC procedures，不使用 RESTful

**理由**: 类型安全，项目已使用 tRPC

---

## AD-004: 状态计算

**决策**: 状态存储在数据库，每次上报时更新

**理由**: 简化查询筛选逻辑

**替代方案**: 动态计算（被否决，筛选不便）

---

## AD-005: MVP 不做权限

**决策**: 所有 API 使用 publicProcedure

**理由**: 需求文档明确"暂不做复杂权限"

**未来**: v0.2 扩展权限系统

---

## AD-006: UI 组件库

**决策**: shadcn/ui + Tailwind + Recharts

**理由**: 需求文档推荐，项目已配置

---

## AD-007: Simulator 独立工具

**决策**: CLI 工具，不集成到主应用

**理由**: 开发调试工具，独立运行更灵活

---

## AD-008: 时间范围预定义

**决策**: 枚举类型 `1h | 6h | 24h | 7d`

**理由**: 符合需求，简化 UI

**未来**: v0.2 支持自定义范围
